موقع صالون أم شهد - Python Flask

التشغيل:
1) ثبّت Python 3.10 أو أحدث.
2) افتح Terminal داخل مجلد المشروع.
3) نفّذ:
   pip install -r requirements.txt
   python app.py
4) افتح:
   http://127.0.0.1:5000

للنشر على الإنترنت:
يمكن رفع المشروع على Render أو Railway أو أي استضافة تدعم Flask.
أرقام التواصل والواتساب موجودة في templates/index.html ويمكن تعديلها.
صور المعرض حالياً روابط صور خارجية، وتحتاج اتصال إنترنت للظهور.
